# AWS Architecture Design

> Tools to design AWS architecture with AWS official icons and guides plus tools to draw the design.

To design an AWS architecture, high-quality icons are needed for clarity and quality of presentation. The tools needed are as follows:

## 1. Draw\.io

Draw\.io can be [downloaded](https://get.diagrams.net/) or accessed online [here](https://app.diagrams.net/).

## 2. AWS Icons

AWS icons may be obtained from draw\.io itself or if you want an ‘HD’ version with the option to choose light/dark mode, you may download it from offical AWS site [here](https://aws.amazon.com/architecture/icons/).
